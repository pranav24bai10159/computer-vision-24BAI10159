# Project Statement

## Title
Simple Computer Vision Image Toolkit

## Problem Statement
Images may have low contrast or unclear boundaries. This project demonstrates a simple Computer Vision pipeline that preprocesses an image and extracts useful edge information.

## Scope
The project performs grayscale conversion, contrast enhancement using CLAHE, Canny edge detection, and basic image analysis. It runs entirely from the command line.

## Target Users
Students, beginners learning OpenCV, and instructors evaluating basic Computer Vision concepts.

## High-Level Features
- Image input and validation
- Grayscale conversion
- Contrast enhancement
- Edge detection
- Image statistics
- JSON reporting
- Automated tests
